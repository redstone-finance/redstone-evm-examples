### Running the Example

1. Navigate to the example directory:
   ```bash
   cd subscription-example
   ```
2. Install the necessary packages:
   ```bash
   npm install
   ```
3. Create an `.env` file from the provided example and add your authorized API key:
   ```bash
   cp .env.example .env
   # Edit .env and insert your API_KEY and WS_URL provided by RedStone
   ```
4. Start the solver script via `ts-node`:
   ```bash
   npm start
   ```
